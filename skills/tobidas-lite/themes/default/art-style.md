# 絵の描き方(切り紙スタイル)

パーツの絵はどの画風でも平塗りの単純な形で描く。縁や質感は画風(`theme.style`)がエンジン側で付ける。既定の `kirigami`(切り紙)では、各パーツに **白い紙の縁(約3.5px)と紙のざらつき** が付く。ほかの画風で気をつける点は `themes/default/presets.md` の表にある。

## 基本

- 形: 円・角丸・なめらかな曲線の `path` を重ねる。輪郭線(stroke の縁取り)は描かない。線が要るのは模様・木の枝・弦のような「細い物そのもの」だけ。
- 色: 平塗り。グラデーションは表紙以外では使わない。1つの物に「基本色+少し暗い色+少し明るい色」の3色まで。影や立体感は、同じ形を少しずらして暗い色で重ねて出す。
- 足元は下端。絵は `w0×h0` の箱の中に描き、地面に接する部分を y=h0 に合わせる。パーツは下端を軸に立ち上がる。
- 旗や芽など、箱の上や横に少しはみ出すのは構わない(下にはみ出すとページに埋まる)。
- 細すぎる形を避ける。幅 6px 未満の形は白い縁に埋もれる。草の葉や指のような細部は太めにまとめる。
- 透明・半透明は控えめにする。半透明の形にも白い縁が付いて濁る。光の粒など紙でない物は `flt: false` を付ける。
- 文字: 看板などは `<text font-family='${FONT}' font-weight="900">`。長い文は字幕に任せる。

## 大きさの目安(見開きは 1440×920)

| 物 | 高さ | 備考 |
|---|---|---|
| 主人公(子ども) | 180〜190 | `A.person` を `k: .82` |
| 大人 | 200〜230 | `k: .9〜1.0` |
| 大きい動物(ろば・牛・馬) | 250〜280 | 人物より少し高いくらい |
| 中くらいの動物(犬・やぎ) | 160〜180 | 実寸より大きめに。小さいと顔がつぶれる |
| 小さい動物(ねこ・にわとり・うさぎ) | 140〜160 | 実寸比を無視して、犬に近い大きさにする |
| 家 | 450 前後 | `A.cottage` を `k: 1.2` |
| 木 | 400〜430 | |
| 背景の丘 | 200〜250 | 幅 1400(背をまたぐ) |
| 巨大な物(塔・巨木) | 1000〜1300 | カメラを引く必要あり |
| 見せ場の建物(城・神殿) | 500〜650 | 板1枚で描かず `terrace()` で段に組む(`gimmicks.md`) |

実寸比にこだわらない。絵本らしく、人物は建物に対して大きめにする(顔が見えることが最優先)。

## 配色

- 1見開きにつき主役の色を1つ決め、地面と背景はそれを引き立てる控えめな色にする。
- 昼の草原: 地面 `#a8d672`、遠い丘は青みがかった `#a5d3e2`、近い丘は `#7cbf66`。遠いほど淡く青く。
- 夜はパーツ自体を暗い色で描いたうえで、見開きの `grade` で全体を青くする(両方やる。grade だけだと単に暗い昼に見える)。
- 肌 `#f6cfa6`、ほお `#f08f7e`、目と口は濃い茶 `#3a2a1e` / `#8a3b2a`。黒は使わない。

## 動かす部分の作り方

動かしたい部分を `<g class="名前">` で包み、回転の中心になる座標を決めておく。

```js
A.dog = () => `
  <g class="tail"><path d="M150 60Q176 40 170 18" stroke="#c98a4a" stroke-width="12" fill="none" stroke-linecap="round"/></g>
  <ellipse cx="100" cy="80" rx="60" ry="34" fill="#d9a066"/> ...`;
// 使う側
pc(200, 700, 200, 140, A.dog(), { anim: (tl, el, q) => rot(qs(el, q, '.tail'), 20 * sin(tl * 9), 150, 60) })
```

`qs` は名前の合う最初の1つしか返さない。1枚の絵に人物と動物を重ねると、どちらにも `.hd` があって、動物の首振りが人物の頭を回すことがある。重なると `check.mjs` が警告する。ただし、検査されるのは撮った時刻に見えているパーツだけ。一瞬しか出ないパーツは、`--spread` で撮る枚数を増やして確かめる。

## 動物の作り方

よく出る動物は目録にある(`parts-lib.md` の犬・猫・鳥・家畜・森の動物など。`put('dog.shiba', …)`)。目録にない動物と、見せ場の主役になる動物(口を開く、首を伸ばす、脚を1本ずつ動かすなど、その場面のための動きを付ける物)は `book/art.js` に描く(聞き取りで「プリセットのみを使う」を選んだ作品は、目録の動物に動きを付けて使う。`parts.md` の「作中の部品の選び方」)。横向き(右向き)で描くと形が伝わりやすい。

- 重ねる順: 奥の脚(暗い色)→ しっぽ → 胴(だ円)→ 手前の脚 → 頭。脚は角丸の長方形で、幅 12px 以上。
- 動かす所は `<g class="tail">` `<g class="hd">` で包み、付け根の座標を控えておく(しっぽを振る・頭をゆらす)。
- 左向きは絵全体を `<g transform="translate(幅 0) scale(-1 1)">` で包む(`{ flip: true }` で切り替えられるようにしておく)。
- **口を開く・閉じるを切り替える**なら、両方の形を `<g class="mo">`(開)`<g class="mc">`(閉)で入れておき、`anim` で `setAttribute('display', …)` を切り替える。絵を2枚用意して差し替えるより軽い。
- 背中に何かを乗せるなら、背中の上端の y を控えておく(`h0 - y` が「背の高さ」。積み重ねで使う)。
- 1匹描いたら、すぐ見開きに置いて `check.mjs` で大きさを見る。最初は小さく作りがちなので、上の表の高さを目安に `k` で合わせる。

## 表紙(738×948)

- 左端 38px は背の帯。題字は上部中央に大きく。金色の枠と題字が定番(見本の `A.cover` を参照)。
- 表紙だけは紙の縁取りが付かないので、グラデーションや細い線を使ってよい。
- 物語を象徴する絵を1つ、中央に大きく置く。

## 地面(1440×920、背は x=720)

- ページに印刷された平らな絵。道・川・畑・床の模様など「立っていない物」を描く。
- 立つパーツの足元に道や影を合わせると、紙面と立体がつながって見える。
- 手前(下)から見下ろすので、縦方向はつぶれて見える。文字や顔は描かない。
