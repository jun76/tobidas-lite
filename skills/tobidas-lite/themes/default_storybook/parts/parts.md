# 共通パーツ一覧(theme/parts/parts.js と theme/parts/parts-*.js)

絵の部品は2通りある。

- **目録の部品**(約300点): 家・木・乗り物・人物・動物・道具などを、名前で呼び出す。まずここから探す。一覧は `parts-lib.md`、見た目は `previews/` の画像。
- **基本の部品**(このファイルの下半分): `A.xxx(...)` で SVG の中身の文字列を返す関数と、動きの部品。目録にない形(丘の色や大きさを細かく決める、人物の服を一から決める、など)に使う。

どちらにもない物は `book/art.js` に `A.名前 = (...) => \`...\`` の形で足す。

## 目録の部品

```js
put('house.log', -350, 440, { k: 1.2 })                    // pieces にそのまま入れる。箱の大きさと既定の動きは目録が持つ
put('tree.sakura', 390, 410, { art: { c: '#f9c6d8' } })     // art に絵の設定(色など)を書く
put('fence.hedge', -300, 760, { art: { w: 620 } })          // 伸び縮みする部品は art の w / h で大きさを決める
put('dog.shiba', 200, 720, { flip: true, k: .9 })           // 生き物と乗り物は右向き。flip: true で左向き
put('kid.girl', 60, 700, { k: .82, art: { armR: -150 }, anim: aArm('.aR', tl => -150 + 20 * sin(tl * 7)) })
lib('tool.axe')                                             // SVG の中身の文字列だけを返す(別の絵に組みこむ、地面に描く、など)
```

- `put(名前, X, Y, 設定)` の設定は `pc()` と同じ(`k` `lift` `dyn` `anim` `nosplit` など。`references/book-api.md`)。加えて `art`(絵の設定)と `flip` が書ける。
- 絵の設定(`art`)に書ける項目は `parts-lib.md` の表にある。色は `c`(主な色)`c2` `c3` が多い。省略すると既定の配色になる。
- **色や大きさなど絵の設定は、必ず `art: { … }` の中に書く。** `put('water.river', 0, 800, { c: '#6fb8e4' })` のように外へ書くと、警告もなく無視されて既定の色のままになる。正しくは `{ art: { c: '#6fb8e4' } }`。`art` の外に書くのは `pc()` と共通の設定(`k` `lift` `delay` `dyn` など)と `flip` だけ。
- 「動き」に ○ のある部品は、置くだけで動く(煙、旗、しっぽ、炎など)。`anim` や `dyn` を渡すと、既定の動きは置きかわる。
- 雲・鳥・気球など空の物は、既定で浮いている(`lift`)。高さを変えるなら `lift` を書く。
- 車や列車を走らせるときは、`dyn` で動かし、`anim: aWheels()` で車輪を回す。
- 人物(`kid.*` `folk.*` `elder.*` `royal.*` `worker.*` `magic.*` `foe.*` `modern.*`)は `A.person` に服・髪・かぶり物・持ち物を着せたもの。`art` に `A.person` の設定(下の「人物」)がそのまま書ける。肌は `skin`、髪の色は `hairC`、服は `top` `bottom`。主人公のように何度も出る人物は、`book/art.js` で `A.hero = o => lib('kid.boy', Object.assign({ top: '#d9534a' }, o))` のように包んでおく。
- 名前を間違えると警告が出て、何も描かれない。

**置き方**

- 大きさは `k` で合わせる。目安は `../art-style.md` の表(主人公 180〜190、家 450 前後、木 400〜430)。目録の箱の高さ × `k` がその高さになるようにする。
- 同じ種類の物を何度も置くときは、種類か色を変える(家なら `house.thatch` と `house.log`、木なら `tree.round` と `conifer.fir`、同じ家でも `art: { c2: … }` で屋根の色を変える)。どの作品も同じ家・同じ木になるのを避ける。
- 題材の国や時代に合う種類を選ぶ(日本の昔話なら `house.thatch` `house.machiya` `gate.mansion` `folk.kimonoMan`、西洋の童話なら `house.stone` `castle.west` `royal.*`)。
- 見た目を確かめたいときは `previews/` の画像を読む(`parts-lib.md` の「画像」の列が、その部品の載っている画像)。

## 作中の部品の選び方

目録の部品をどこまで使うかは、聞き取りの「作中の部品」の答えで決まる(SKILL.md の手順1)。聞き取りページの「プリセット」は、目録の部品を指す。答えは構成表に書き、作品の途中で変えない。

### プリセットを使い、ないものは描き下ろす(既定)

- 目録にある物は目録の部品を使い、目録にない物は `book/art.js` に描く。
- **目録の部品は、置くだけにせず作品に合わせて調整する。** 既定の配色のまま並べると、どの作品も同じ見た目になる。次のどれかを必ず行う。
  - 色を作品の色合いに合わせる(`art: { c, c2, c3 }`。人物は `skin` `hairC` `top` `bottom`)。画風と場面(夜、雪、夕焼け)に合う色を選ぶ。
  - 人物は服・髪・持ち物・腕の角度・表情を、その登場人物に合わせて決める(`art` に `A.person` の設定を書く)。
  - 動きをその場面に合わせる(`anim` `dyn` を渡す。手を振る、うなずく、走る、など)。
  - 目録の絵を元に描き足す: `lib(foe.oni)` の上に開いた口や金棒を振る腕を重ねる、`lib(house.thatch)` に看板や洗濯物を足す、など。`book/art.js` に `A.名前 = o => lib(…) + \`…\`` の形で書く。
- **見せ場の主役には目録の部品を使わない。** その場面で観る人の目が向く物(巨人、鬼、竜、大だこ、主人公、見せ場の建物や乗り物)は、`book/art.js` にその作品のために描く。目録の絵は、口を開ける、首を伸ばす、目をむく、脚を1本ずつくねらせる、といった動きに合わせて作られていないので、主役に使うと場面が平らになる。描くときは、動かす部分を `<g class="…">` で分けておく(`../art-style.md` の「動かす部分の作り方」)。見本: `examples/jack/book/art.js` の大男(`A.giant`。腕・脚・頭と、3通りの目・開いた口と閉じた口をクラスで分けて描き、`aGiant` で場面ごとに「いねむり」「追いかける」「木につかまる」の動きと表情を切り替える)。
- 目録の部品は、まわりを固める物に使う(背景の家、木、通りすがりの人や動物、小道具)。見せ場でない見開きの登場人物は、目録の人物を `art` で着せ替えて使ってよい。

### プリセットのみを使う

- 絵は全部、目録の部品(`put()` `lib()`)と、下の「基本の部品」で組む。見せ場の主役も目録の部品にする。`book/art.js` に新しい絵は描かない(`A.hero = o => lib(kid.boy, …)` のように目録の部品を包む関数は書いてよい)。
- 目録にない物は、近い部品の色や大きさを変えて代わりにするか、部品を組み合わせて表す。どの部品で表すかは構成表に書く。話に欠かせない物で代わりがどうしても見つからないときは、構成表でそのことを伝え、その1点だけ描いてよいかを尋ねる。
- 色・服・大きさ・動きの調整は、既定の答えと同じように行う。見せ場は、部品を分けて描いた動きの代わりに、部品にある動かせる部分(人物の `.aL` `.aR`、動物の `.hd` `.tail` など。`parts-lib.md` の「動き」)、全体の動き(`dyn`)、仕掛けの型(`../gimmicks.md`)で作る。

### プリセットを使わない

- 絵は全部 `book/art.js` にその作品のために描く。`put()` `lib()` は使わない。下の「基本の部品」のうち、絵を返す関数(`A.person` `A.cottage` `A.tree` など)も使わない。地面の関数(`A.gMeadow` など)は使ってよい。
- 動きの部品(`aArm` `aFlap` など)、仕掛けの型、背景の書き方は、ほかの答えと同じように使う。
- 人物は、顔・体・服の描き方を作品の中でそろえる(頭身、目の描き方、輪郭)。先に主人公を1人描いて最初の見開きで撮り、大きさと顔を確かめてから、同じ描き方でほかの人物を描く。
- 動かす部分は `<g class="…">` で分けて描く(`../art-style.md` の「動かす部分の作り方」)。
- 描く量が多くなる。構成表を作るときに、見開きごとに描く物を数え、背景の物は1つの関数を色や大きさの引数で使い回す。

## 基本の部品

すべて「SVGの中身の文字列」を返す。`pc(X, Y, w0, h0, A.xxx(...), {...})` の `art` に渡す。色の引数は省略すると既定の配色になる。

### 人物 A.person()

```js
A.person({
  top: '#4f9d4a',        // 上着の色
  bottom: '#8a6238',     // ズボン/スカートの色
  long: false,           // true で長い裾(ドレス・ローブ)
  skin: '#f6cfa6',
  hair: `<path .../>`,   // 髪・帽子・ひげ(頭は中心(60,58) 半径29。その上に重ねて描く)
  extra: `...`,          // 胴に重ねる物(ベルト・エプロン)
  armL: 14, armR: -14,   // 腕の角度(度)。下ろした状態が0。外へ上げるには armL は正、armR は負(±150 でばんざい)
  holdL: `...`, holdR: `...`,   // 手に持つ物(腕と一緒に回る。腕を下ろした状態で手は (40,150)/(80,150))
  mouth: 'smile',        // 'smile' | 'o'(おどろき)| 'big'(大笑い)| 'flat'(真顔。しずかな場面・悲しい場面)
  eyes: 'closed',        // 目を閉じる(眠る・祈る・気を失う)。省略すると開いた目
  look: 'up',            // 上を見る
  flip: true,            // 左右反転
})
```

登場人物ごとに `A.momo = (o = {}) => A.person(Object.assign({ top: ..., hair: ... }, o))` の形で包むと、場面ごとに `A.momo({ armR: -150, mouth: 'big' })` とポーズだけ変えられる。腕は `anim: aArm('.aR', tl => 角度)`(左腕は `aArm('.aL', f, 40)`)で動かす。体格の違う者(巨人・動物)は骨格を使わず専用に描く。

### 地面(見開きの `ground` 用、1440×920)

| 関数 | 説明 |
|---|---|
| `A.gMeadow({seed, night, path, pond})` | 草原。`path` は小道のSVGパス(null でなし)、`pond` は池の位置 `[x, y]`(null でなし) |
| `A.gSky()` | 雲の上 |
| `A.gFloor()` | 市松の床と赤いじゅうたん |

返り値に `+` で SVG を足して、畑・川・影などを描き加えられる。

### 動きの部品

| 名前 | 使い方 |
|---|---|
| `aSun(s)` | 太陽や光の `.rays` を回す |
| `aSmoke` | `A.cottage` の煙 |
| `aFlag` | `.flag` の旗を、ポール(path の始点)を軸にはためかせる。自作の旗も、ポールの上端から描き始めた path に `class="flag"` を付ければ使える |
| `aCow` | `A.cow` のしっぽと頭 |
| `aArm(sel, tl => 角度, 肩x)` | 人物の腕。右腕 `'.aR'`(肩x=80)、左腕 `'.aL'`(肩x=40) |
| `aFlap(速さ, 中心y)` | `.wg` を羽ばたかせる |
| `aWheels(速さ)` | 目録の乗り物の車輪(`.wh`)を回す。速さは 度/秒(既定 200) |
| `many(a, b, ...)` | 複数の anim をまとめる |

### 小物パーツ(pc を返す。pieces にそのまま入れる)

| 名前 | 説明 |
|---|---|
| `bird(X, Y, 高さ, 速さ, 位相, 色)` | 横切って飛ぶ鳥 |
| `fly(X, Y, 色, 位相)` | ひらひら舞うちょう |
| `twinkle(X, Y, 高さ, 位相, 半径, 色)` | またたく星・きらめき |
| `note(X, Y, 位相, 色)` | 立ちのぼる音符 |
| `GR` | 花の色の配列 |
