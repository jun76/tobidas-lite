# 音の付け方(BGM と効果音)

音は `engine/sound.js` が作品定義から**ブラウザ内で合成**する(音色は曲集ごとに違う。旋律と伴奏だけでなく、効果音と本そのものの音も、曲集に合わせた音色で鳴る)。音声ファイルは要らない(ユーザーが用意した音声ファイルを混ぜることもできる。`references/assets.md`)。作品全体を1本の波形として先に作っておくので、**どの位置から再生しても、その時刻の音から始まる**。鳴るのは自動再生中(▶ボタン / Space)だけで、ホイールで動かしている間は鳴らない。

作品側で書くのは「見開きごとの気分」と「効果音を鳴らす時刻」だけ。

```js
{
  hold: 9.2,
  music: 'bright',                                   // BGMの気分
  sfx: [[1.5, 'pop'], [3.4, 'sparkle', { len: 1.6 }]],   // [tl, 効果音の名前, 設定]
  ...
}
```

何も書かなくても、表紙のきらきら・ページをめくる音・パーツが立ち上がる音・本をとじる音・おしまいの和音は自動で付き、BGM は `'bright'` になる。

音つきの作品では、曲集を書き下ろす場合も表紙はエンジンの短いメロディーに任せ、BGMは最初の見開きから始める。表紙にBGMを重ねるのは、ユーザーが明示的に希望した場合に限る。

曲そのものは曲集(`sound: { set: 'march' }` など。内蔵5種、または書き下ろし)で決まる。一覧と書き方は `themes/default_storybook/presets.md`。下の「気分」は曲集の3曲(明るい主題・もうひとつの明るい曲・短調)を速さや高さを変えて使い分ける。

## `music` BGMの気分

| 名前 | 感じ | 向く場面 |
|---|---|---|
| `bright` | 明るい・ふつうの速さ(既定) | はじまり、日常 |
| `gentle` | ゆったり・小さめ | のどかな場面、語り |
| `airy` | 広々・わくわく | 旅立ち、新しい場所 |
| `happy` | 華やか | めでたし、宴 |
| `triumph` | 速くて晴れやか | やった! の直後 |
| `night` | 短調・低め・しずか | 夜、ふしぎ |
| `sad` | 短調・おそい | 別れ、しょんぼり |
| `creepy` | 短調・歯切れよく・低め | しのび足、こわい場所 |
| `chase` | 短調・速い | 追いかけっこ、危機 |
| `none` | 無音 | 見せ場の直前のため |

- **同じ気分が続く見開きは、めくりをまたいで1本の曲としてつながる。** 気分を変えるのは場面の空気が変わる所だけにする(全見開きで変えると落ち着かない)。
- 見開きの途中で変えるときは配列で書く: `music: [[0, 'night'], [2.4, 'none'], [8.1, 'bright']]`(`[tl, 気分]`)。**見せ場の仕掛けの間は `'none'` にして効果音だけにすると、仕掛けが引き立つ。**
- 細かく決めたいときは名前の代わりに設定を書く: `{ tune: 'majA', beat: .6, vol: .7, tr: 0, oct: 0, stac: false, dbl: false, startBar: 0 }`。`tune` は `main`(明るい主題)`sub`(もうひとつの明るい曲)`minor`(短調)、`beat` は1拍の秒数(小さいほど速い)。

## `sfx` 効果音

`[tl, 名前, 設定]` を並べる。`tl` は動き(`dyn` / `anim`)に使った時刻と同じ値にする。**動きの時刻を定数にしておき、絵と音の両方で使う**とずれない(見本の `FALL` `IMPACT`)。

| 名前 | 音 | 主な設定(既定) |
|---|---|---|
| `sparkle` | きらきら | `len`(1.5) `n`(10) `vol`(.4) `base`(96 高さ) |
| `magic` | しゃらん+きらきら | `len`(1.6) |
| `chime` | しゃらん(上昇) | `notes` `gap`(.05) |
| `fanfare` | やった! | `gap`(.07) |
| `bell` | ちりん | `vol`(.6) |
| `pop` | ぽん(現れる) | `vol`(.5) |
| `drop` | ぽとぽと(小さい物が落ちる) | |
| `fall` | ひゅるる(下降) | `gap`(.14) |
| `rise` | ぐんぐん伸びる(加速する上昇音階+最後にしゃらん) | `len`(4.5) `finish`(true) |
| `whoosh` | 風切り・たおれる | `len`(1.3) |
| `wind` | そよ風 | `len`(3) |
| `creak` | きしむ | `len`(.5) |
| `thud` | どん | `vol`(.4) `f0`(85) |
| `crash` | どしーん(大きな衝撃。`shake` と同じ時刻に) | `vol`(1) |
| `steps` | のしのし | `n`(6) `gap`(.44) |
| `knock` | とんとん | `n`(3) |
| `chop` | かつん(切る・打つ) | |
| `splash` | ばしゃ | |
| `snore` | ぐうぐう | `n`(1 回数) `period`(3.9) `pan` |
| `tick` | かちっ | |

- 音程のある効果音(きらきら、しゃらん、ぽん、やった! など)は、曲集の音色で鳴る。オルゴールならオルゴール、鼓笛隊なら笛、ハープならハープ、和笛ならはじく弦、チップチューンなら矩形波。風・水・打撃のような雑音の効果音は共通で、チップチューンだけ雑音が粗くなる。効果音の名前と書き方は、どの曲集でも同じ。
- 1見開きの効果音は 2〜5個が目安。BGM の上に重ねすぎると濁る。
- 無い音は関数で作れる: `[2.0, (S, t) => { S.box(t, 88, .6); S.noise(t, .3, u => 2000, u => (1 - u) * .2); }]`。`S.box(t, MIDI, 音量, 左右, 残響)` オルゴール、`S.soft(t, MIDI, 音量, 長さ)` 低音、`S.noise(t, 長さ, 周波数(u), 音量(u), q, 左右, 残響, 'bp'|'lp'|'hp')` ノイズ、`S.thud(t, 音量, 周波数, 長さ)` 打撃、`S.sparkle(t0, t1, 個数, 音量)`、`S.sfx('名前', t, 設定)`。`t` は全体の秒数。

## 全体の設定(`Tobidas.book({ sound: … })`)

| 書き方 | 意味 |
|---|---|
| `sound: false` | 音なしの作品にする(スピーカーのボタンも消える) |
| `sound: { auto: false }` | 表紙・めくり・とじるの自動の音を付けない |
| `sound: { moods: { march: { tune: 'majA', beat: .45, stac: true } } }` | 気分を足す |
| `sound: { set: 'march' }` | 曲集を選ぶ(内蔵の名前、または書き下ろしのオブジェクト。`themes/default_storybook/presets.md`) |
| `sound: { music: false }` | 合成のBGMを付けない(本の音と効果音は残る。音声ファイルのBGMに任せるとき) |
| `sound: { files: [{ src: 'assets/bgm.mp3', vol: .7 }] }` | 音声ファイルを混ぜる(`references/assets.md`) |
| `sound: { extra: S => { … } }` | 自由に鳴らす(`S.O(見開き番号)` で開いた時刻が取れる) |

## 確かめ方

`check.mjs` が音も合成し、名前の間違い(警告)と 2秒以上の無音区間を報告する。**音色や曲の良し悪しは耳で聞かないと分からない**ので、聞けていないときは渡すときにそう伝える。
