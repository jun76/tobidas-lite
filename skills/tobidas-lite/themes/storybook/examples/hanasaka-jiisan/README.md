# はなさかじいさん

日本語・全6見開き、約77秒の飛び出す絵本。切り紙風の絵、場面別に書き下ろした背景と和風のオリジナルBGM。

制作モデル: **GPT-6 Astra medium**

## 開く

このリポジトリを取得し、`index.html` をブラウザで開いてください。サーバーやネット接続は不要です。エンジンとテーマはスキル内の共通ファイルを参照するため、移動・共有するときは `skills/tobidas-lite/` 全体の構成を保ってください。

- ホイール：進む／戻る
- ← →：前後の見開き
- 左下の ▶ または Space：音つき自動再生／一時停止
- M：音のオン／オフ
- Home / End：最初／最後

## 内容

1. おじいさん・おばあさん・しろの暮らし
2. ここほれ、わんわん — 小判の発見
3. しろとの別れと、お墓の木
4. ふしぎな臼から小判、臼から灰へ
5. 灰をまいて、枝ごとに桜が開く
6. 隣人の失敗、殿さまの褒美、花びらの結び

伝承の筋を短く再話しています。犬の死には字幕で触れ、暴力の場面は直接描いていません。声のナレーションはありません。

## 制作と確認

`tobidas-lite` の storybook テーマを使用。エンジン・テーマはスキル内の共通ファイルを参照し、絵・背景・音楽・場面は `book/art.js` と `book/book.js` に定義しています。表紙はエンジンの短い旋律、BGMは最初の見開きからです。

- 全見開き・ページめくり・表紙・結びを27枚の画像で確認。
- 各見開きの段階的な仕掛けを追加の画像で確認。
- 音の合成成功、長い無音なし、エラー・警告なし。
- Chromeでホイール・矢印・音つき再生・一時停止・ミュートの操作を自動確認。
- 実機での動きの滑らかさと、耳による音楽の試聴は未確認。
- スキルへのフィードバックはありません。

`preview.jpg` は桜の見せ場、`.check/sheet.jpg` は検証用一覧です。
