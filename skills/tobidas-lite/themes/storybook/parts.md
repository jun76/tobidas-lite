# 共通パーツ一覧(theme/parts.js)

すべて「SVGの中身の文字列」を返す。`pc(X, Y, w0, h0, A.xxx(...), {...})` の `art` に渡す。色の引数は省略すると既定の配色になる。足りない物は `book/art.js` に `A.名前 = (...) => \`...\`` の形で足す。

## 背景・自然

| 関数 | 元サイズ | 説明 |
|---|---|---|
| `A.hills(w, h, 色, 手前の色, seed, うねり, deco)` | w×h | 連なる丘。背をまたぐ背景の定番(w=1400前後、h=200〜250)。`deco` に `hillTrees(本数, seed, 大きさ, 針葉樹も混ぜるか)` を渡すと稜線に木が並ぶ(木は絵の箱の上端を出ない場所・大きさに自動で収まる。自作の飾りを稜線に置くときも、箱の上へはみ出すと切れる) |
| `A.cloud(w, h, seed, 色, 影色)` | w×h | 雲ひとつ(260×110 など) |
| `A.cloudBank(w, h, seed, 色, 影色)` | w×h | 横に長い雲の帯(1420×110 など) |
| `A.puff(w, h, seed)` | w×h | 土ぼこり・煙 |
| `A.tree(w, h, {c, c2, c3, fruit})` | w×h | 広葉樹(300×430)。`fruit` に色を渡すと実がなる |
| `A.pine(x, y, s, 色)` / `A.miniTree(x, y, s)` | — | 小さな木。**座標つきの部品**なので、複数を1つの絵にまとめて使う |
| `A.bush(w, h, 色, 色2, 花色)` | w×h | 花つきの茂み(280×120)。手前に置く |
| `A.grass(w, h, 色, 色2, 花色の配列)` | w×h | 草むら(240×90)。花色に `GR` を渡すと花が咲く |
| `A.fence(w, h)` | w×h | 木の柵(440×90) |
| `A.sun(s)` | s×s | 顔つきの太陽(200)。`anim: aSun(s)` で光が回る。子ども向けの明るい話に |
| `A.sunDisc(s, 色, 芯の色)` | s×s | 顔のない太陽(240)。夕日・朝日や、落ち着いた題材に。`flt: false` と `glow: 24` を付けて使う |
| `A.moon(s)` | s×s | 月(180) |
| `A.rainbow(w, h)` | w×h | 虹(1060×500) |
| `A.star(cx, cy, r, 色)` | — | きらめき。座標つき部品 |

## 人物 A.person()

```js
A.person({
  top: '#4f9d4a',        // 上着の色
  bottom: '#8a6238',     // ズボン/スカートの色
  long: false,           // true で長い裾(ドレス・ローブ)
  skin: '#f6cfa6',
  hair: `<path .../>`,   // 髪・帽子・ひげ(頭は中心(60,58) 半径29。その上に重ねて描く)
  extra: `...`,          // 胴に重ねる物(ベルト・エプロン)
  armL: 14, armR: -14,   // 腕の角度(度)。下ろした状態が0。外へ上げるには armL は正、armR は負(±150 でばんざい)
  holdL: `...`, holdR: `...`,   // 手に持つ物(腕と一緒に回る。腕を下ろした状態で手は (40,150)/(80,150))
  mouth: 'smile',        // 'smile' | 'o'(おどろき)| 'big'(大笑い)| 'flat'(真顔。しずかな場面・悲しい場面)
  eyes: 'closed',        // 目を閉じる(眠る・祈る・気を失う)。省略すると開いた目
  look: 'up',            // 上を見る
  flip: true,            // 左右反転
})
```

登場人物ごとに `A.momo = (o = {}) => A.person(Object.assign({ top: ..., hair: ... }, o))` の形で包むと、場面ごとに `A.momo({ armR: -150, mouth: 'big' })` とポーズだけ変えられる。腕は `anim: aArm('.aR', tl => 角度)`(左腕は `aArm('.aL', f, 40)`)で動かす。体格の違う者(巨人・動物)は骨格を使わず専用に描く。

## 地面(見開きの `ground` 用、1440×920)

| 関数 | 説明 |
|---|---|
| `A.gMeadow({seed, night, path, pond})` | 草原。`path` は小道のSVGパス(null でなし)、`pond` は池の位置 `[x, y]`(null でなし) |
| `A.gSky()` | 雲の上 |
| `A.gFloor()` | 市松の床と赤いじゅうたん |

返り値に `+` で SVG を足して、畑・川・影などを描き加えられる。

## 動きの部品

| 名前 | 使い方 |
|---|---|
| `aSun(s)` | 太陽や光の `.rays` を回す |
| `aSmoke` | `A.cottage` の煙 |
| `aFlag` | `.flag` の旗を、ポール(path の始点)を軸にはためかせる。自作の旗も、ポールの上端から描き始めた path に `class="flag"` を付ければ使える |
| `aCow` | `A.cow` のしっぽと頭 |
| `aArm(sel, tl => 角度, 肩x)` | 人物の腕。右腕 `'.aR'`(肩x=80)、左腕 `'.aL'`(肩x=40) |
| `aFlap(速さ, 中心y)` | `.wg` を羽ばたかせる |
| `many(a, b, ...)` | 複数の anim をまとめる |

## 小物パーツ(pc を返す。pieces にそのまま入れる)

| 名前 | 説明 |
|---|---|
| `bird(X, Y, 高さ, 速さ, 位相, 色)` | 横切って飛ぶ鳥 |
| `fly(X, Y, 色, 位相)` | ひらひら舞うちょう |
| `twinkle(X, Y, 高さ, 位相, 半径, 色)` | またたく星・きらめき |
| `note(X, Y, 位相, 色)` | 立ちのぼる音符 |
| `GR` | 花の色の配列 |
