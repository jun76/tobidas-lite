# 定番の仕掛け

どれも `tl`(見開きが開ききってからの秒数)の関数として書く。見本 `themes/storybook/examples/jack/book/book.js` に実例がある。仕掛けを入れた見開きは `node scripts/check.mjs <作品> --spread N` で時間方向に確認する。

## ぽんと現れる(途中で登場)

```js
pc(-150, 720, 120, 226, A.hero(), { nosplit: true,
  dyn: tl => ({ sc: pop(tl, 7.0), op: tl > 7.0 ? 1 : 0 }) })
```
`pop` は 0→1 に少し行き過ぎて戻る。`op` で登場前を隠すのを忘れない。

## 歩く・走る(ページ内の移動)

```js
dyn: tl => { const u = sm((tl - .8) / 5.2);                  // 0.8秒後から5.2秒かけて
  return { dx: 330 * u, lift: u > 0 && u < 1 ? 9 * abs(sin(tl * 5)) : 0 }; }   // 歩く間だけ上下に弾む
```
背をまたいで歩かせるなら `nosplit: true, side: 'L'`(出発側のページ)。背を越えたら、いまいる側のページに自動で付け替わるので、めくるときはそのページと一緒にたたまれる。

## 飛び跳ねる・よろこぶ

`dyn: tl => ({ lift: 40 * abs(sin(tl * 4)) })` と、腕を `aArm` で振る。複数人は位相をずらす(`sin(tl * 4 + 1)`)。

## 投げる・飛ぶ(放物線)

```js
dyn: tl => { const u = cl((tl - .7) / 1.0);
  return { dx: 300 * u, dy: 130 * u, lift: 200 * (1 - u) + 520 * u * (1 - u), rz: tl * 500, op: u > 0 && tl < 3 ? 1 : 0 }; }
```
`lift` の `u*(1-u)` が山なりの軌道。小さい物は `glow` を付けると見失わない。

## 段々の構造物(城・塔・神殿・ひな壇)

見せ場になる建物は板1枚ではなく `terrace()` で組む(書き方は `references/book-api.md` の「段々の構造物」)。壁と床が連動して開閉する定型なので、決めるのは「段の並び」と「各段の正面の絵」だけ。

段の並びの型(手前 → 奥):

| 建物 | 段の並び |
|---|---|
| 和風の城・社寺 | 石の台 → 軒先 → 壁(入口)→ 軒先 → 上の階の壁 → 屋根飾り |
| 西洋の城 | 城壁(胸壁つき)→ 門のある壁 → 左右の塔を描いた壁 → 中央の高い塔 |
| 階段ピラミッド・塔 | 幅を 0.75 倍ずつ狭め、高さを同じだけ足していく壁を 4〜6 段。床は石の色 |
| ひな壇・舞台・客席 | 同じ幅の低い壁を 3〜5 段。床を広めにして、人物を段の上に立たせる |
| 階段状の町 | 家並みを描いた壁を 3〜4 段。床は屋根の色か道の色 |

- 背の上(`X: 0`)に置く。壁が山折りになって建物の角がこちらを向き、はじめて立体に見える。片ページに置いた構造物や、浅い谷折りは、1枚絵に見える。
- 奥の段ほど高く、幅は同じか狭く。隣り合う段の高さの差が「見える部分」になるので、差は 100 以上にする。
- 軒先・欄干の段は、上の 70 ほどだけ描いて下は透明にする。屋根の面(`top`)は `td` で奥の壁まで渡す。
- 見本: `examples/urashima` の竜宮城(`A.palaceTiers` と見開き5・7)。見開き5は `sink` で海底からせり上がる。

## 下から伸びる(木・塔・つる)

高さいっぱいの絵を描いておき、`clip`(上から隠す割合)を 1→0 にする。

```js
const growU = tl => sm((tl - 2.7) / 4.5);
pc(30, 600, 260, 1300, A.stalk(260, 1300), { nosplit: true, side: 'R', delay: 0,
  dyn: tl => { const g = growU(tl); return { clip: 1 - g, op: g > 0 ? 1 : 0 }; } })
```
- 同じ絵を `yaw: 90` でもう1枚置いて十字に組むと、どの角度からも太く見える。
- 幹に人物をつかまらせるなど、すぐ手前に物を置くときは、2枚を `yaw: 45` と `yaw: -45` の X 字に組み、手前の物の Y を「板の幅の半分 × 0.71」より大きく離す(幅 260 なら 100 以上)。十字のままだと、真横向きの板が手前の物を突き抜けて縦の線に見える。
- カメラを `keys` で引く(`d: 1150, tilt: 72, cz: 560` など)。伸びきった先端が画面に入るか必ず確認する。
- 先端に雲などを `lift` で浮かせ、`pop` で後から出すと高さが伝わる。
- **高さ 1000 を超える板は、上下2枚に分けて置く。** 1枚のままだと、カメラが近いとき(`d` 250〜520、既定の `tilt`)に板の下のほうが描かれず、上のほうだけが浮いて見える(カメラを引くと正しく出るので、引いたコマだけ見ていると気づかない)。下の板はそのまま根元に置き、上の板は同じ根元に `lift`(下の板の高さ)で浮かせて `sh: false` にする。絵は、全体の絵の一部だけを箱に描く関数で作り分ける。

```js
// 全体 w×h の絵のうち、上端 y0〜下端 y1 の部分だけを、w×(y1−y0) の箱に描く(clipPath の id は呼ぶたびに変える)
let partN = 0;
const partTop = y0 => y0 ? 0 : -80;                  // 切り抜く四角の上端(いちばん上の板は、先の葉が箱の上へ出る分を足す)
A.stalkPart = (w, h, y0, y1) => { const id = 'stk' + (partN++);
  return `<clipPath id="${id}"><rect class="gr" x="-200" y="${partTop(y0)}" width="${w + 400}" height="${y1 - y0 - partTop(y0)}"/></clipPath><g clip-path="url(#${id})"><g transform="translate(0 ${-y0})">${A.stalk(w, h)}</g></g>`; };
// 下から伸びる動き: 切り抜く四角を、下から g(0〜1)の割合だけ開ける。同じ id の切り抜きを全部動かす(下の注意)
const aGrow = (y0, y1, f) => (tl, el, q) => {
  const rs = q.gr || (q.gr = document.querySelectorAll(`[id="${qs(el, q, 'clipPath').id}"] .gr`)), top = partTop(y0), H = y1 - y0 - top, g = cl(f(tl));
  const y = (top + (1 - g) * H).toFixed(1), hh = (g * H).toFixed(1); rs.forEach(r => { r.setAttribute('y', y); r.setAttribute('height', hh); }); };

const SPLIT = 860, LOW = (1300 - SPLIT) / 1300;      // 上の板の高さと、下の板が全体に占める割合
const lowG = tl => growU(tl) / LOW, upG = tl => (growU(tl) - LOW) / (1 - LOW);   // 下の板が伸びきってから、上の板が伸びる
pc(30, 600, 260, 1300 - SPLIT, A.stalkPart(260, 1300, SPLIT, 1300), { nosplit: true, side: 'R', delay: 0, sway: 0,
  anim: aGrow(SPLIT, 1300, lowG), dyn: tl => ({ op: lowG(tl) > 0 ? 1 : 0 }) }),
pc(30, 600, 260, SPLIT, A.stalkPart(260, 1300, 0, SPLIT), { nosplit: true, side: 'R', delay: 0, sway: 0, sh: false, lift: 1300 - SPLIT,
  anim: aGrow(0, SPLIT, upG), dyn: tl => ({ op: upG(tl) > 0 ? 1 : 0 }) }),
```
  - **分けた板は、`dyn` の `clip` ではなく、絵の中の切り抜き(上の `aGrow`)で伸ばす。** `yaw` で回して `lift` で浮かせた板に `clip` を使うと、板の下のほうが欠けて、上のほうだけが浮いて見える(`yaw: 0` の板では起きない)。十字や X 字に組むと必ず当たるので、向きにかかわらず切り抜きで伸ばす。伸びる途中のコマ(上の板が半分ほど出たところ)を撮って確かめる。
  - **切り抜きは、板の中の1つだけでなく、同じ id のものを全部動かす(上の `aGrow`)。** 影を付ける板(`sh: false` でない板)は、エンジンが同じ絵を板と影の2か所に入れるので、同じ id の切り抜きが2つできる。板の絵は先にある影の側の切り抜きを参照するため、板の中の1つだけを動かすと、板は最初から全部見えたまま動かず、伸び始めに急に現れる。伸び始めの直後のコマも撮って確かめる。
  - 継ぎ目には2枚それぞれの紙の縁が出る。葉や節などの小さな絵を、同じ根元に `lift`(継ぎ目の高さ)で浮かせて重ね、かくす。X 字に組むときは、この絵を板より手前(Y を 30 ほど大きく)に置く。
  - 倒すときは、下の板を `rz`、上の板と継ぎ目の絵を `rzBase` で同じ角度だけ回す(下の「倒れる」)。2枚とも `sway: 0` にして、継ぎ目がずれないようにする。
  - X 字に組んだ板(`yaw: ±45`)は、`rz` `rzBase` だと板ごとに斜めの別の向きへ倒れる。そろえて横へ倒すには、倒す回転を `yaw` `lean` `rzBase` の3つの角に分けて `dyn` で返す(見本の `fallX`)。
  - 見本: `examples/jack` の見開き3(伸びる)と見開き7(倒れる)。`book/art.js` の `A.stalkPart` `aStalkGrow` `A.stalkKnot`、`book/book.js` の `fallX`。

## 傾いて沈む(船・塔)

大きな物が傾きながら水や地面に沈む。板そのものは傾けず、**板の中の絵を回して傾け、板ごと `sink` で沈める**(板を `rz` で傾けると、水面の線も一緒に傾いてしまう)。沈んだ分は根元の線(水面)で切れる。

```js
const tiltU = tl => sm((tl - .8) / 4.2), sinkU = tl => sm((tl - 3.6) / 5);
const art = `<g class="sk">${A.ship()}</g>`;                       // 回す部分をクラスで包む
pc(0, 440, 1100, 900, art, { fold: 18, sh: false,                  // 背の上に置くなら折る。回した絵が箱から出ると切れるので、箱の高さを大きく取り、絵は箱の下に寄せる
  anim: (tl, el, q) => rot(qs(el, q, '.sk'), 30 * tiltU(tl), 760, 900),   // 回す中心は、沈みはじめる側の水面あたり(箱の下端)
  dyn: tl => ({ sink: 1 + 540 * sinkU(tl), op: 1 - sm((tl - 8) / .6) }) }) // sink は 1 以上にしておく(回してはみ出した下側を切るため)
```
- 段々の構造物(`terrace()`)は傾けられないので、傾く場面はこの1枚板の型にする。
- 窓の灯りを消す・ちらつかせるなら、灯りを `<g class="wl">` で包み、`anim` で `opacity` を変える。

## 倒れる

```js
const fallU = tl => Math.pow(cl((tl - 4.05) / 1.45), 2.3);          // 重力らしく加速
dyn: tl => ({ rz: 88 * fallU(tl), op: 1 - sm((tl - 6.0) / .8) })    // 右へ倒れ、消える
```
- `yaw: 90` の板は `rz` ではなく `lean: 88 * fallU(tl)` で同じ向きに倒れる。
- 倒れる物につかまっている物は、同じ根元に置いて `rzBase` で一緒に振り回す。
- 高さ 1000 を超える物は上下2枚に分けてあるので(上の「下から伸びる」)、下の板を `rz`、上の板を `rzBase` で同じ角度だけ回す。
- 十字や X 字に組んだ物は、板ごとに倒れる向きが変わる。`yaw: 90` の板は上のとおり `lean`、`yaw: ±45` の X 字は `yaw` `lean` `rzBase` の3つに分けて回す(上の「下から伸びる」、見本 `examples/jack` の `fallX`)。
- 着地の瞬間に `shake`、土ぼこり(`A.puff` を `sc` で広げ `op` で消す)、切り株などの「跡」を `op` で出す。

## 積み重ねる(肩車・タワー)

同じ場所に `lift` を変えて重ねる。下の物の「背の高さ × k」を足し上げた値を `lift` にする。

```js
const LIFT = [0, 184, 288, 364];                       // 1段目の背・2段目の背…を積み上げた高さ
pc(TX,      TY,     300, 240, A.donkey(), { nosplit: true, dyn: tower(0) }),
pc(TX + 14, TY + 2, 200, 150, A.dog(),    { nosplit: true, sh: false, dyn: tower(1) }),   // Y を 2 ずつ手前へ
const tower = i => tl => { const t0 = i ? STACK[i - 1] : -9, u = cl((tl - t0) / .45);
  return { lift: LIFT[i] + (1 - u) * (1 - u) * 380, op: tl > t0 ? 1 : 0 }; };            // 上から降ってきて乗る
```
- **Y を少しずつずらす**(同じ Y に重ねると、どれが前に描かれるか決まらない)。上の段は `sh: false`。
- 高さ 500 程度までなら、カメラは `d: 380〜470, tilt: 58〜60, cz: 290〜330` で足りる。引きすぎると全体が小さくなる。

## 窓ごしに見せる(穴のあいた壁)

壁の絵を `fill-rule="evenodd"` の path で描き、窓の部分を穴にする。奥(Y が小さい側)に明るい部屋の板・人物・家具を `lift` で窓の高さに浮かせて置くと、窓ごしに中が見える。中の人物を `lift` と `dx` で飛び出させれば「逃げ出す」になる。

## ページの下から出てくる

`lift` を負にするとページの下に隠れる。`dyn: tl => ({ lift: -200 + 330 * sm(tl / 2.2) })` で穴や雲の中から登ってくる。手前に雲や茂みを置くと出入り口が自然に隠れる。

## 浮かぶ・ただよう

高く浮かせた物(`lift` 300 以上)を見開きの最初から出すと、立ち上がりで大きく弧を描いて振れる。泳ぐ・飛ぶ主役は `op: sm((tl + .5) / .6)` で、開ききる直前にふわっと現すと落ち着く。

雲・太陽・月・星は `lift` で浮かせ、`sh: false`。雲は `dyn: tl => ({ dx: 40 * sin(tl * .3) })` でゆっくり流す。鳥・ちょう・星・音符は `bird()` `fly()` `twinkle()` `note()` を置くだけ。

## 繰り返し立ちのぼる(湯気・Zzz・泡・紙ふぶき)

```js
dyn: tl => { const u = (((tl * .4 + i / 3) % 1) + 1) % 1;            // 0→1 を繰り返す。i で位相をずらして複数置く
  return { lift: 520 + u * 230, dx: u * 120, sc: .4 + u, op: sin(u * PI) }; }
```
降る物(紙ふぶき・雪・花びら)は `lift: 760 * (1 - u)`。

## 受け渡す・光る

2人の間を物が移る: `dx: -150 * u, lift: 118 + 70 * sin(u * PI)`(山なり)。受け取る側・渡す側の腕も同じ `u` で動かすと連動する。大事な物には `glow` と、まわりに `twinkle()` を2〜3個。

## 昼夜・天気が変わる

`grade: tl => ['#3d52a8', .56 * (1 - sm((tl - 5) / 3.2))]` で夜明け。パーツ側も夜の色で描いておく(grade だけでは夜に見えない)。月と星は `lift` で高く、`glow` を強めに。

## 道具を振る(おの・剣・つえ)

持ち物は `A.person` の `holdR` に描くと腕と一緒に回る。振り下ろしは「速く下ろし、ゆっくり戻す」。

```js
const HIT = [1.2, 2.0, 2.8];
const swing = tl => { let a = -150; for (const c of HIT) { const u = (tl - c + .22) / .22;
  if (u > 0 && u < 1) a = -150 + 105 * u * u; else if (u >= 1 && u < 2.6) a = -45 - 105 * sm((u - 1) / 1.6); } return a; };
```
当たる瞬間に火花(`A.star` を `sc: sin(u * PI)` で一瞬)と、相手側の小さなゆれを同じ時刻で入れる。
