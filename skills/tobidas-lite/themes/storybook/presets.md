# 内蔵の表現と、書き下ろすときの書き方

画風・机・曲はそれぞれ **内蔵から選ぶ** か **その作品のために書き下ろす** かを、最初の聞き取りでユーザーが決める。書き下ろしはユーザーが選んだときだけ行い、選ばれなかった項目は必ず内蔵を使う(内蔵は見え方・聞こえ方を確認済みで、誰が作っても同じ結果になるため)。

見本画像: `themes/storybook/previews/styles.jpg`(画風)、`themes/storybook/previews/desks.jpg`(机)。作り直すには `node scripts/gallery.mjs themes/storybook/examples/jack --out themes/storybook/previews`。
作品を開いたまま試すには、URL に `?style=crayon&desk=felt&set=march` を付ける(作品定義より優先される)。画風は再生ボタンの横のプルダウンでも切り替えられる。

## 画風 `theme.style`

パーツの絵そのものは `themes/storybook/art-style.md` のとおり平塗りで描き、画風はその上にかかる仕上げ(縁・質感・色合い)として切り替わる。

| 名前 | 見え方 | 向く題材 | 描くときの注意 |
|---|---|---|---|
| `kirigami`(既定) | 白い紙の縁と紙のざらつき。色紙の工作 | 何にでも合う | — |
| `flat` | 縁なし・質感なしの平らな色面 | 現代的な話、乗り物、図鑑ふう | 隣り合うパーツは色をはっきり変える(縁がないので同系色は溶ける) |
| `crayon` | 輪郭がゆらぎ、粗い質感。クレヨン画 | 素朴な昔話、手づくり感を出したい話 | 幅 10px 未満の形はゆらぎで切れる。文字は読みにくくなるので大きく |
| `vintage` | くすんだ暖色、生成りの縁。古い絵本 | 西洋の古典童話、なつかしい話 | 色がくすむので、主役は彩度の高い色で描く |

書き下ろし(`theme.style` をオブジェクトで書く):

```js
theme: { style: {
  base: 'kirigami',            // 指定しなかった項目はこの内蔵の値を使う
  filter: `<feMorphology in="SourceAlpha" operator="dilate" radius="5" result="d"/><feFlood flood-color="#ffe9f2"/><feComposite in2="d" operator="in" result="edge"/><feMerge><feMergeNode in="edge"/><feMergeNode in="SourceGraphic"/></feMerge>`,
  pageFilter: 'saturate(.9)',  // ページに印刷された地面の絵にかける CSS フィルタ(省略可)
  grain: .5,                   // ページの紙のざらつき 0〜1
  shadow: 1,                   // パーツの影の濃さの倍率
} }
```

- `filter` は SVG フィルタの中身(`<filter>` タグは不要)。**最後の要素の結果が表示される。** 入力は `SourceGraphic`(絵)と `SourceAlpha`(形)。
- すべてのパーツに毎フレームかかるので軽く保つ。`feGaussianBlur` の大きな値や `feDisplacementMap` の重ねがけは、実機で動きが重くなる。
- 書いたら `check.mjs` で全場面を見る。顔が判別できるか、細い形が消えていないかを確かめる。

## 机・背景 `theme.desk`

本の後ろに見えるものを選ぶ。**机**(本を机に置く)と、**動く背景**(机を置かず、軽くぼかした景色の前に本を浮かべる)がある。

| 名前 | 見え方 | 向く題材 |
|---|---|---|
| `wood`(既定) | こげ茶の板張り。暖かい灯り | 何にでも合う |
| `lightwood` | 明るい白木 | 明るい話、現代的な話 |
| `linen` | 生成りの麻布 | やさしい話、手芸ふう |
| `felt` | 深緑のフェルト | クリスマス、森の話、西洋の古典 |
| `marble` | 白い大理石。白っぽい光 | お城、お姫さま、上品な話 |
| `grass` | 芝生。まわりは青空の色 | 野外の話、ピクニック、動物 |
| `night` | 星空。青い光 | 夜の話、宇宙、七夕 |
| `sky` | 雲の浮かぶ青空。明るい白い光 | 空の話、鳥や飛ぶ物の話、晴れやかな話 |
| `mat` | 緑のカッティングマット | 工作らしさを強調したいとき |

動く背景(雲・波・草・葉・電車などがゆっくり動く。作品のじゃまにならないよう軽くぼかしてある):

| 名前 | 見え方 | 向く題材 |
|---|---|---|
| `seaside` | 空と雲、寄せては返す波、沖の帆かけ舟、かもめ、手前に砂浜 | 海の話、船や魚の話、夏の話 |
| `meadow` | 流れる雲、重なる丘、風にゆれる草花、舞う綿毛 | 野原の話、動物の話、のどかな昔話 |
| `forest` | 光のさす森の奥、かすむ遠くの木立、広葉樹と針葉樹、手前を縁どる太い幹と茂み、木もれ日の筋、舞い落ちる葉と光の粒 | 森の話、冒険、ふしぎな話 |
| `town` | 夕方前の空、かすむ遠くの塔、屋根の形がいろいろの家並みとまたたく窓、アーチの高架を走る電車、煙突のけむり、気球 | 町の話、現代の話、乗り物の話 |

机に合わせて、まわりの部屋の色と光の色も変わる。動く背景では、机に散らす小物(`tableDeco`)は描かれない。`wood` だけは `theme.table: [左の色, 右の色]` で板の色を変えられる。

書き下ろし:

```js
theme: { desk: {
  base: 'wood',                                   // 指定しなかった項目はこの内蔵の値
  background: `radial-gradient(circle, #f7c9d6 0 14px, rgba(0,0,0,0) 15px) 0 0/90px 90px, linear-gradient(90deg,#fbe4ea,#f3cfd9)`,   // 机の面の CSS background
  room: ['#6a4a55', '#33222a', '#170f13'],        // まわりの部屋の色(中心・中間・外)
  light: '255,230,236',                           // 光の色 'r,g,b'
} }
```

- 机の面は 6000×4600px で、斜めから見下ろす。模様は 20px 以上の大きさにする(細かい模様は遠くでちらつく)。
- 机の面(`background`)は CSS のグラデーションか、データURLの SVG で描く。画像ファイルを背景に使うなら、動く背景(`scene`)の SVG に `img()` で置く(`references/assets.md`)。
- 本と字幕が主役なので、机は彩度と明暗差を控えめにする。字幕は白なので、画面下が明るすぎる机は避ける。
- **背景を書き下ろすときは、見開きごとに書く。** 各見開きに `scene: { svg, anim, blur }` を書き(`references/book-api.md` の「見開きごとの背景」)、表紙と結び用の1つを `desk: { base: 'seaside', scene: { … } }` の形で書く。内蔵を選んだときは全見開き共通で、見開きには書かない。書式と注意は `references/theme-format.md` の「動く背景」。

## 曲 `sound.set`

曲集1つは3曲(`main` 明るい主題 / `sub` もうひとつの明るい曲 / `minor` 短調)でできていて、見開きの `music`(気分)がこの3曲を速さや高さを変えて使い分ける(`themes/storybook/sound.md`)。

| 名前 | 感じ | 向く題材 |
|---|---|---|
| `musicbox`(既定) | 3拍子のオルゴール | 西洋の昔話、何にでも合う |
| `march` | 4拍子の行進曲。元気 | 冒険、旅、動物たちの行進 |
| `lullaby` | 3拍子でゆったり。やさしい | 小さい子向け、おやすみ前の話、しずかな話 |
| `wafu` | 4拍子の五音音階。和風 | 日本の昔話 |

```js
Tobidas.book({ ..., sound: { set: 'march' }, ... })
```

書き下ろし(`sound.set` をオブジェクトで書く。書かなかった役は `musicbox` の曲になる):

```js
sound: { set: {
  tr: 0,          // 全体の移調(半音)
  tempo: 1,       // 速さの倍率(大きいほど遅い)。4拍子なら .8 前後が合う
  main: {
    beats: 3,                                                  // 1小節の拍数(3 か 4)
    chords: ['C', 'Am', 'F', 'G', 'C', 'Am', 'Dm', 'C'],       // 小節ごとの和音。8小節を基本にする
    mel: [[[0, 76], [1, 79], [2, 84]], [[0, 83], [1.5, 81], [2, 79]], …],   // 小節ごとの [拍(0〜beats), MIDI音程]
  },
  sub:   { … },   // 明るい曲をもう1つ(main と違う和音進行で)
  minor: { … },   // 短調の曲(夜・こわい場面・追いかけっこ用)
} }
```

- 使える和音: `C Am F G Dm E G7 Em D7 C7 Bb Gm`。ハ長調/イ短調で書き、高さは `tr` で変える。
- 音程は MIDI 番号(60=ド, 62=レ, 64=ミ, 65=ファ, 67=ソ, 69=ラ, 71=シ, 72=高いド)。旋律は 72〜93 の範囲に収める(オルゴールの音色がきれいに鳴る高さ)。
- **各小節の1拍目はその小節の和音に含まれる音にする**(C なら ド・ミ・ソ)。それ以外の拍は音階の音でつなぐ。最後の小節は主音(`main`/`sub` はド、`minor` はラ)で終える。これを守れば大きく外れた響きにはならない。
- 1小節に 2〜4音。8小節のうち 1〜2小節は音を減らして息つぎを作る。
- `check.mjs` は和音名の間違いと、`chords` と `mel` の小節数の不一致を警告する。**曲の良し悪しは検査できない**ので、書き下ろしたときは「耳では確かめていない」と伝えて聞いてもらう。
