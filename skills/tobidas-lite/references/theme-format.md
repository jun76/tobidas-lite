# テーマパックの書式

テーマは「どんな見た目と音の作品にするか」をまとめた1つのフォルダで、フォルダごと差し替えられる。エンジン(本の機構・時間軸・操作・音源)と作品定義の書式(`references/book-api.md`)は全テーマ共通で、テーマはその上に素材と作り方を載せる。

この資料はテーマを新しく作るとき・直すときだけ読む。作品を作るだけなら不要。

## フォルダの中身

```
themes/<名前>/
  theme.js      必須。画風・机・曲などを登録する(下記)
  parts/        任意。絵の部品(下記「parts/」)
    parts.js      絵の部品と動きの部品(作品の art.js / book.js から使う)
    parts-*.js    部品を分けて書くときの追加のファイル(parts.js の次に、名前の順で読み込まれる)
    parts.md      部品の使い方の資料
    parts-lib.md  名前で呼び出す部品の一覧(scripts/parts-sheet.mjs で作る)
    previews/     部品の見本画像(scripts/parts-sheet.mjs で作る)
  *.css         任意。テーマ用のスタイル
  assets/       任意。テーマが使う画像・音声ファイル(作品の theme/assets/ にコピーされる。作品からは 'theme/assets/…' で指定。書き方は references/assets.md)
  guide.md      必須。向く用途、聞き取りで決めること、資料を読む順
  *.md          任意。そのテーマの資料(一覧、描き方、仕掛けなど)
  previews/     聞き取りページが使う見本画像と一覧 index.json(scripts/gallery.mjs で作る)
  starter/book/ 任意。新しい作品の書き出し(art.js と book.js)
  examples/     任意。完成見本
```

`scripts/new-book.mjs` は、このうち **直下の `.js` `.css`、`assets/`、`parts/` の `.js`** だけを作品の `theme/` にコピーし、`starter/book/` を作品の `book/` にコピーする。資料・見本画像・完成見本は作品には入らない。

作品の `index.html` は エンジン → `theme/theme.js` → `theme/parts/parts.js` →(あれば)`theme/parts/parts-*.js` → `book/art.js` → `book/book.js` → 操作系 の順に読み込む。サーバーなし(`file://`)で開けるように、どれもモジュールではない普通のスクリプトにする。

## theme.js

```js
(function () {
  const { edge, grain, tex, noise, planks, grid } = Tobidas.fx, B = Tobidas.sound.bars;
  Tobidas.theme({
    id: 'default_storybook',            // フォルダ名と同じ
    label: '童話の絵本',
    engine: 1,                  // 対応するエンジンの版(Tobidas.VERSION より大きいと警告が出る)
    defaults: { style: 'kirigami', desk: 'wood', set: 'musicbox' },   // 作品が指定しなかったときに使う名前
    styles: { 名前: {...}, ... },
    desks:  { 名前: {...}, ... },
    sound:  { tunes: {...}, sets: {...}, moods: {...}, sfx: {...} },
  });
})();
```

作品側は `theme: { style: '名前', desk: '名前' }` と `sound: { set: '名前' }` で選ぶ。名前の代わりにオブジェクトを書くと、その作品だけの書き下ろしになる(`base` に書いた内蔵をもとに、書いた項目だけ上書き)。

### `styles` 画風

パーツの絵にかける仕上げ。すべてのパーツに毎フレームかかるので軽く保つ。

| 項目 | 意味 |
|---|---|
| `label` | 表示名 |
| `filter` | SVG フィルタの中身(`<filter>` タグは不要)。**最後の要素の結果が表示される。** 入力は `SourceGraphic`(絵)と `SourceAlpha`(形) |
| `pageFilter` | 任意。ページに印刷された地面の絵にかける CSS フィルタ |
| `grain` | ページの紙のざらつき 0〜1 |
| `shadow` | パーツの影の濃さの倍率 |

フィルタを書く部品(`Tobidas.fx`): `edge(半径, 色, 名前)` 形を太らせた縁(結果名は `名前`、既定 `edge`)/ `grain(傾き, 切片, 細かさ)` 紙のざらつき(結果名 `g2`)/ `tex(元, 形)` 元の絵にざらつきを掛ける(結果名 `tex`)。

### `desks` 机・背景

本の後ろに見えるもの。**机**(本を置く面)か、**動く背景**(机の面を置かず、本の後ろいっぱいに景色を敷く)のどちらか。作品側の指定はどちらも `theme.desk`。

| 項目 | 意味 |
|---|---|
| `label` | 表示名 |
| `background` | 机のとき必須。机の面の CSS background(文字列、または `th => 文字列`。`th` は作品の `theme`)。面は 6000×4600px で斜めから見下ろすので、模様は 20px 以上にする |
| `room` | まわりの部屋の色3つ(中心・中間・外) |
| `light` | 光の色 `'r,g,b'` |
| `scene` | 動く背景のとき書く(下記)。`scene` があって `background` がなければ、机の面は描かれない |

背景を書く部品: `noise(横の細かさ, 縦の細かさ, 色行列, タイルの大きさ)` ノイズ模様のデータURL / `planks(線の色, 色行列, [左の色, 右の色])` 板張り / `grid(色, 間隔, 線幅)` 格子。大きくゆるやかな模様は、タイルを並べると継ぎ目が見えるので、大きさ 1500 のタイルを `0 0/6000px 6000px` で引きのばして1枚で敷く。

**動く背景(`scene`)**: 本の後ろ(3D の外、画面いっぱい)に SVG を1枚敷き、軽くぼかして見せる。

```js
seaside: { label: '海辺(動く背景)', room: [...], light: '255,250,226',
  scene: {
    svg: th => `...`,                 // 1920×1080 の SVG の中身(文字列、または th => 文字列)。画面の縦横比に合わせて中央を切り出して敷かれる
    anim: (t, el, q) => { ... },      // 省略可。t 秒の絵にする。el は SVG 要素、q はキャッシュ用の入れ物
    blur: 5,                          // ぼかし(px)。既定 5。0 でぼかさない
    shadow: .4,                       // 本の下の影の濃さ。既定 .4(机より薄くして、景色の前に浮いて見せる)
  } }
```

- **動きは `t` の関数にする**(`Date.now()` は使わない)。`t` は環境の時計で、再生中は実時間、静止画チェックでは作品の時刻が渡る。同じ `t` なら同じ絵になること。
- 動かす要素にクラスを付け、`anim` で `transform` や `opacity` を書き換える。位置の初期値は `data-x` などに持たせておくと、毎フレームの計算が単純になる。
- **本が画面中央を占める**ので、見どころは上3分の1と左右に寄せる。ぼかして見せるので細部は描かない。字幕は白で画面下に出るので、下端は明るくしすぎない。
- 作品が見開きごとに背景を書く場合(見開きの `scene`)も、この書式を使う。そのとき机の `scene` は表紙と結びに出る。
- 毎フレーム全体がぼかし直されるので軽く保つ。動かす要素は 100 個程度まで、SVG フィルタは使わない。
- 机に散らす小物(作品の `tableDeco`)は、机の面がないので描かれない。

### `sound` 音

音源(オルゴール・低音・ノイズ・打撃)と、本そのものの音(表紙・ページめくり・とじる)はエンジンが持つ。テーマが持つのは曲と効果音。

| 項目 | 意味 |
|---|---|
| `tunes` | 曲。`{ beats: 3か4, chords: [小節ごとの和音], mel: [小節ごとの [拍, MIDI音程] の並び] }`。`B([音程, …], …)` で「1拍に1音」の略記ができる(0 は休み)。和音は `C Am F G Dm E G7 Em D7 C7 Bb Gm` |
| `sets` | 曲集。`{ label, main: 曲名, sub: 曲名, minor: 曲名, tr: 移調(半音), tempo: 速さの倍率, inst: 音色 }`。`inst` は `{ mel, comp, pad, bass, perc, fx, noise }` で旋律・伴奏・伸ばす弦・低音・打楽器・効果音の音色を選ぶ(書かなければオルゴール。値は `engine/sound.js` の `VOICE` と `phrase`)。`main`=明るい主題、`sub`=もうひとつの明るい曲、`minor`=短調 |
| `moods` | 気分(見開きの `music` に書く名前)。`{ tune: 'main'|'sub'|'minor', beat: 1拍の秒数, vol, tr, oct, stac, dbl, startBar }` |
| `sfx` | 効果音(見開きの `sfx` に書く名前)。`(S, t, o) => {…}`。`S.box` `S.soft` `S.noise` `S.thud` `S.tick` `S.sparkle` `S.seq(t, [音程…], 間隔, 音量, 残響)` `S.sfx(名前, t, 設定)` で鳴らす。`t` は全体の秒数、`o` は作品が渡した設定 |

乱数は `S.rand()` を使う(`Math.random()` を使うと、同じ作品でも鳴るたびに音が変わり、動画化や検査で再現しない)。

## parts/

作品の `art.js` と `book.js` から使う部品を、`parts/parts.js` に普通のスクリプトとして定義する。約束は2つある。

- 絵の部品は名前空間 `A` に「SVG の中身の文字列を返す関数」として足す(`const A = {};` はテーマの parts.js が定義する)。
- 動きの部品や小物(`pc()` を返す関数)は、グローバルの関数として定義する。

部品が多いときは `parts-*.js` に分けてよい。`new-book.mjs` が、作品の `index.html` に `theme/parts/parts.js` の次へ読み込みを足す(名前の順)。

名前で呼び出す部品をまとめるなら、default_storybook の「目録」と同じ形にする: `defPart(名前, 表示名, 幅, 高さ, (絵の設定, 幅, 高さ) => SVG, pc の既定の設定, 絵の設定の説明)` で登録し、作品からは `put(名前, X, Y, 設定)` / `lib(名前, 絵の設定)` で使う(`themes/default_storybook/parts/parts.js` の「部品の目録」)。`node scripts/parts-sheet.mjs --theme <テーマ>` が、登録した部品の見本画像(`parts/previews/`)と一覧(`parts/parts-lib.md`)を作る。

部品の一覧と寸法は、そのテーマの資料に書く。

## guide.md

作品を作るモデルが、テーマを決めた直後に読む。次を必ず書く。

1. **向く用途**(冒頭の数行)。テーマが複数あるとき、ここを見て選ぶ。
2. **聞き取りで決めること**。項目ごとに、内蔵の名前の一覧と、作品定義での書き方。
3. **資料を読む順**。
4. **見本**の場所。

## テーマを作る・直すときの確かめ方

- `node scripts/new-book.mjs <一時フォルダ> --theme <名前>` で作品フォルダが作れ、`node scripts/check.mjs <一時フォルダ>` がエラー・警告なしで通る。
- `node scripts/gallery.mjs <見本の作品> --out themes/<名前>/previews` で、全部の画風と机を並べた見本画像を作り、目で見る。同時に、1種ずつの画像と一覧 `index.json`(画風・机・曲集の名前と、当てはめて見せる見本の場所)ができる。聞き取りページ(`scripts/setup.mjs`)はこれを読むので、見本の作品はテーマの `examples/` の下のものを渡す。
- 曲集は URL に `?set=<名前>` を付けて `check.mjs` を通す(和音名の間違い、小節数の不一致が警告される)。曲の良し悪しは耳で聞くしかない。
- テーマが読み込まれていない・名前が間違っているときは、エンジンが警告を出し、仕上げなし・無地の机・曲なしで動く。

## まだ決まっていないこと

次は書式にまだ無い。必要になったテーマを作るときに、エンジンの拡張と合わせて決める。

- 音源(音色)の差し替え
- 字幕・最後の画面・常時表示(ロゴや帯)の見た目の差し替え
- テーマごとの既定のカメラ・時間配分
