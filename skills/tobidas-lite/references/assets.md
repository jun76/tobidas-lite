# 画像・音声ファイルを使う(任意)

既定では、絵は SVG、音はブラウザ内の合成だけで作る。**ユーザーが素材を用意したとき、または素材を作って使うよう指示したとき**に限り、画像ファイルと音声ファイルを作品に入れられる。頼まれていないのに素材を探したり生成したりしない。動画ファイルは素材として扱わない(完成した作品を動画に書き出す `render-video.mjs` とは別の話)。

目次: [置き場所](#置き場所) / [画像](#画像) / [音声](#音声) / [確かめ方と渡し方](#確かめ方と渡し方)

## 置き場所

作品フォルダの `assets/`(`new-book.mjs` が作る)に置く。作品からは **`index.html` から見たパス**(`'assets/hero.png'`)で指定する。フォルダごと渡せば動くように、外部の URL は使わない。

```
<作品>/
  assets/
    hero.png  backgrounds.jpg     画像
    bgm.mp3  bark.wav             音声
    audio.js                      embed-audio.mjs が作る(手で編集しない)
```

素材の出どころ(生成に使ったプロンプト、配布元、ライセンス)は、作品フォルダの `README.md` に書いておく。

## 画像

`img(パス, w, h, 設定)` が `w×h` の箱に画像を置く SVG 片を返す。パーツ、ページの地面、表紙、背景(`scene`)など、SVG を書く所ならどこでも使え、SVG の絵と混ぜてよい。

```js
pc(-300, 600, 240, 360, img('assets/hero.png', 240, 360)),                       // 透過PNGの人物
pc(0, 120, 1400, 260, img('assets/hills.jpg', 1400, 260, { fit: 'slice' })),     // 箱を埋める背景
pc(200, 640, 200, 300, img('assets/cast.png', 200, 300, { crop: [540, 0, 280, 724], size: [2172, 724] })),   // 1枚の画像の一部
```

| 設定 | 意味 |
|---|---|
| `fit` | `'meet'` 全体が入るように置く(既定。下端・中央ぞろえなので、足もとがパーツの根元に合う)/ `'slice'` 箱を埋めて余りを切る / `'fill'` 縦横比を変えて箱いっぱい |
| `crop` と `size` | `crop: [x, y, 幅, 高さ]` で画像の一部だけを切り出す。`size: [画像全体の幅, 高さ]` を必ず添える。人物や小物を1枚にまとめた画像(アトラス)に使う |

- **箱の縦横比は画像(切り出すなら切り出す範囲)に合わせる。** 合っていないと、`meet` では箱の中に余白ができて影や根元がずれる。
- **立つパーツには透過PNG(背景が透明)を使う。** 画風の仕上げ(紙の縁取りと質感)は画像にもかかり、透過PNGなら輪郭に沿って白い縁が付いて切り紙になじむ。不透明の画像は四角い紙になる(写真や絵はがきとして見せるならそれでよい)。仕上げを付けたくないパーツは `flt: false`。
- 画像の実寸は表示する大きさの 1〜2 倍で足りる(パーツは `w×h`×`k` の大きさで表示され、カメラが寄っても 2 倍あれば荒れない)。大きすぎる画像は動きを重くする。
- 背をまたぐパーツの制約(箱の外は描かれない、など)は SVG の絵と同じ。
- 画像は全部読み込んでから作品が始まる。読み込めない画像は警告になる(`check.mjs` が報告する)。

## 音声

音声ファイルは合成した音(本の音・効果音・BGM)と**同じ1本の波形に混ぜる**。どの位置から再生してもその時刻の音から始まり、無音の検査も動画化もそのまま使える。対応する形式は mp3 / wav / ogg / m4a / aac / flac(ブラウザが読めるもの。mp3 か wav が無難)。

**BGM や長い音**は全体の `sound.files` に書く。

```js
sound: {
  music: false,                                  // 合成のBGMを止める(ファイルのBGMに任せるとき)。本の音と効果音は残る
  files: [
    { src: 'assets/bgm.mp3', vol: .7 },                                  // 最初の見開きから、本をとじる所まで
    { src: 'assets/night.mp3', spread: 4, endSpread: 5, vol: .6, loop: true },   // 見開き4〜5のあいだ、くり返して流す
  ],
}
```

| 項目 | 既定 | 意味 |
|---|---|---|
| `src` | — | ファイルのパス |
| `at` / `spread` と `tl` | 最初の見開きが開く所 | 始める時刻。`at` は全体の秒数、`spread: n, tl: 秒` は見開き n が開ききってからの秒数 |
| `end` / `endSpread` | 本をとじる所 | 終わる時刻。`end` は全体の秒数、`endSpread: n` は見開き n をめくる所まで。ファイルのほうが短ければそこで終わる |
| `vol` | 1 | 音量の倍率。合成の音と重ねるなら .5〜.8 から始める |
| `loop` | false | 終わりまでくり返す |
| `from` | 0 | ファイルの何秒目から使うか |
| `fadeIn` / `fadeOut` | .6 / 2.5 | 入りと終わりをなめらかにする秒数 |

- 表紙は既定どおりエンジンの短いメロディーに任せ、BGMは最初の見開きから始める(`sound.md` と同じ方針)。
- 合成のBGMと重ねると濁るので、ファイルのBGMを使う区間は `music: false`(全体)か、見開きの `music: 'none'` で合成を止める。
- 曲の長さが作品に合わないときは、`loop` でくり返すか、`end` で早めに終わらせる。曲に合わせて見開きの `hold` を調整してもよい。

**効果音や短い声**は見開きの `sfx` に、名前の代わりにパスを書く。

```js
sfx: [[1.5, 'pop'], [3.2, 'assets/bark.wav', { vol: .8 }]],   // [tl, パス, 設定]。設定は vol / from / fadeIn / fadeOut
```

### 埋め込み(必ず行う)

ブラウザは `file://` で開いたページから音声ファイルの中身を読めない。そこで、音声を `assets/audio.js` に埋め込んで読み込む。**音声ファイルを足した・差し替えたら、そのたびに実行する。**

```bash
node <このスキル>/scripts/embed-audio.mjs <作品フォルダ>
```

`assets/` の音声を全部 `assets/audio.js` に入れ、`index.html` に読み込みの1行(`engine/sound.js` の次)を足す。作品定義のパスは元のまま(`'assets/bgm.mp3'`)でよい。埋め込んでいない音声は警告「読み込めません」になる。

## 確かめ方と渡し方

- `check.mjs` は画像・音声が読み込めないときに警告を出し、音声を混ぜたあとの波形で無音区間を調べる。警告は全部直す。
- 音は合成と同じく耳では確かめられない。音量のつり合い(BGMと効果音、合成の音とファイルの音)は聞いてもらう必要があると伝える。
- 渡すときは、`assets/` を含む作品フォルダごと渡す。`assets/audio.js` があれば元の音声ファイルは再生には使われないが、差し替えのために残しておく。
