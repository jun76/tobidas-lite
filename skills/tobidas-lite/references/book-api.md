## 全体の形

```js
Tobidas.book({
  title: 'ももたろう とびだすえほん',      // ブラウザのタブ名
  lang: 'ja',                              // 'ja' 以外なら操作ヒントが英語になる
  theme: { board: '#7a2f2f', spine: '#5a1f1f', style: 'kirigami', desk: 'wood' },   // 装丁の色と、画風・机(themes/<テーマ>/presets.md)。ほかに pickers: false(左上の画風・背景・曲のプルダウンを出さない。stylePicker: false なら画風だけ)、paper, font(字幕・結びの文字のフォント。日本語以外の作品は欧文フォントを指定する)
  timing: { intro: 5.2, turn: 2.4, close: 2.8, outro: 3.8 },   // 省略可(この値が既定)
  cover: A.cover(),                        // 表紙の絵。738×948 のSVGの中身(紙の縁取りなし)
  end: { title: 'おしまい', sub: 'ももたろう' },
  tableDeco: (i, r) => `<circle r="8" fill="#f4b"/>`,   // 省略可。机に散らす小物(原点まわりに描く。i=番号, r()=乱数)
  sound: { set: 'musicbox' },              // 曲集(themes/<テーマ>/presets.md)。ほかの設定は themes/<テーマ>/sound.md。false で音なし。音声ファイルを混ぜるなら files(references/assets.md)
  spreads: [ { ... }, { ... } ],           // 見開きを順に
});
```

`index.html` は エンジン(tobidas.js, sound.js)→ テーマ(theme/theme.js, theme/parts.js)→ book/art.js → book/book.js → player.js の順に読み込む。モジュールではなく普通の `<script>` なので、art.js で定義した `A.xxx` や定数は book.js からそのまま使える(`file://` で開けるようにするため)。

## 座標系

見開き座標で書く。単位は px 相当(見開き全体で 1440×920)。

```
        X = -720 ……… 0(本の背)……… +720
Y = 0    ┌───────────┬───────────┐   奥(画面の上・遠い)
         │  左ページ  │  右ページ  │
Y = 920  └───────────┴───────────┘   手前(画面の下・近い)
```

- パーツの位置 `(X, Y)` は **根元の中央**。そこを軸に、ページから垂直に立ち上がる。
- 立ったパーツは手前(カメラ側)を向く。高さ方向はページから上へ。
- 重なりは実際の奥行きで決まる。Y が大きいパーツが手前に来て、奥のパーツを隠す。
- カメラは斜め上から見下ろすので、奥のパーツは高く・小さく見え、上端が画面上部に来る。
- 目安: 背景 Y=100〜250、建物や木 Y=400〜450、人物 Y=600〜720、手前の草 Y=780〜870。

地面の絵(`ground`)だけは別の座標で、左上原点の 1440×920(背は x=720)。

## 時間

- 全体の時刻 `t`(秒)がホイールで前後する。各見開きには持ち時間 `hold` がある。
- パーツの動きは **`tl` = その見開きが開ききってからの秒数** で書く(めくり途中は負)。見開きの最後は `tl = hold`。
- 動きは必ず `tl` の関数にする。`Date.now()` や `requestAnimationFrame` は使わない。巻き戻し・静止画チェック・動画化が成り立つのは、同じ `tl` に対して常に同じ絵になるから。
- ずっと繰り返す動きは `sin(tl * 速さ)`、ある時点で起きる動きは `sm((tl - 開始) / 長さ)`(0→1 に滑らかに進む)で書く。

## 見開き

```js
{
  hold: 7.5,                                   // 開いている秒数(既定 7.5)。見せ場は 9〜10
  ground: A.gMeadow({ seed: 5 }),              // ページに印刷された地面(1440×920 のSVGの中身)
  pieces: [ pc(...), pc(...), ... ],           // 立ち上がるパーツ
  caption: ['1行目', '2行目'],                 // 字幕。省略するとなし。行を [tl, '文'] と書くと、その時刻になってから出る(見せ場のせりふを先に見せないため)
  cam: { start: {...}, end: {...}, keys: [[tl, {...}], ...] },   // 省略可
  grade: tl => ['#3d52a8', .5],                // 省略可。画面全体の色調
  shake: tl => [x, y],                         // 省略可。画面のゆれ(px)
  music: 'bright',                             // 省略可。BGMの気分(themes/<テーマ>/sound.md)
  scene: { svg, anim, blur },                  // 省略可。この見開きのあいだだけ、本の後ろの背景をこれに替える(下記)
  sfx: [[1.5, 'pop'], [3.4, 'sparkle']],       // 省略可。効果音 [tl, 名前, 設定]
}
```

**見開きごとの背景(`scene`)**: 本の後ろの背景を書き下ろす作品で使う。書式は机の動く背景と同じ(`references/theme-format.md` の「動く背景」: `svg` は 1920×1080 の SVG の中身、`anim(t, el, q)` は動き、`blur` はぼかし)。

- その見開きへめくる間に現れ、次へめくる間に消える(前後の背景となめらかに入れ替わる)。
- 表紙と結びには `theme.desk` の背景が出る。`theme.desk` が机(背景なし)のときは、最初と最後の見開きの `scene` が表紙と結びにも使われ、机の面は描かれない。
- **書くなら全部の見開きに書く**(`theme.desk` に動く背景があれば、`scene` のない見開きではそれが出る)。背景のない見開きが残るとエンジンが警告を出す。
- `<defs>` の `id`(グラデーションなど)は背景ごとに違う名前にする(同じ名前だと、別の背景の色が使われる)。
- ぼかしの強さは、最初の背景の `blur` が全体に使われる。
- 内蔵の机・動く背景を選んだ作品では書かない(全見開き共通)。

## パーツ pc()

```js
pc(X, Y, w0, h0, art, options)
```

- `w0, h0` … 絵の元サイズ。絵は左上原点の `w0×h0` に描き、**足元が下端(y=h0)** に来るようにする。
- `art` … SVG の中身の文字列(`<svg>` タグは不要)。
- `options`:

| キー | 既定 | 意味 |
|---|---|---|
| `k` | 1 | 拡大率。`w0,h0` は元サイズのまま書き、大きさは `k` で調整する |
| `lift` | 0 | ページから浮かせる高さ。太陽・雲・鳥・星など |
| `yaw` | 0 | 根元の線の向き(度)。90 で本の背と平行に立つ。0 の板と十字に組むと立体感が出る |
| `lean` | 0 | 後ろへ倒す角度(度) |
| `sway` | 0.9 | 紙のゆらゆら(度)。背景や建物は 0〜0.3、木は 1.4 |
| `delay` | Yから自動 | 立ち上がりの遅れ 0〜0.4。既定は奥から順に立つ |
| `sh` | true | 影を落とすか。背景の丘や浮いている小物は `false` |
| `shOp` | 1 | 影の濃さの倍率 |
| `flt` | true | 紙の縁取りと質感を付けるか。光の粒など紙でない物は `false` |
| (絵) | — | 絵には画像ファイルも使える: `img('assets/hero.png', w, h)`(`references/assets.md`) |
| `glow` | なし | 光らせる(ぼかし半径 px、30 まで。それより大きい値は 30 として扱う)。色は `glowC`。もっと広く光らせたいときは、絵の側に半透明の大きな円を重ねる |
| `nosplit` | false | 背をまたいでも左右に切り分けない(下記) |
| `fold` | 自動 | 背をまたぐパーツを背で折る角度(度)と向き(符号)。下記。左右とも 200 以上張り出すパネルは ±12、ほかは 0(折らない) |
| `side` | Xの符号 | 取り付けるページ `'L'`/`'R'`。`nosplit` で X が 0 付近のとき指定 |
| `dyn` | なし | `tl => ({...})` 位置や大きさの動き |
| `anim` | なし | `(tl, el, q) => {...}` 絵の中身の動き |

**背をまたぐパーツ**: 幅が X=0 をまたぐパーツは、自動で左右のページに切り分けられる。そのうち **左右とも背から 200 以上張り出す横長のパネル**(背景の丘・壁・虹など)は、背の位置で浅い「くの字」に折れた1枚の板になる(本物の飛び出す絵本のV字折りと同じ)。

**背を少しだけまたぐ置き方はしない。** 片側の張り出しが 200 未満のパーツは自動では折られず、左右の板が別々に立つので、ページをめくるとき背の位置で分断されて見える。エンジンが警告を出すので、次のどれかで必ず直す。

1. **片ページに収める**(はみ出しが小さいとき。机・柵・茂みの端が背を越えた、など): X をずらすか幅を縮めて、パーツの端を背から 4 以上離す。警告に直す X の値が出る。
2. **くの字に折る**(背の上に置きたいとき。中央の家・門・木など): `fold: 12`(端が手前)か `fold: -12`(端が奥)を書く。向きは下の規則と同じ考え方で選ぶ。
3. **`nosplit: true`**(動かす物・`yaw` を付ける物): 切り分けず、片方のページに付ける。

意図して分断のまま使うときだけ `fold: 0` を書く(警告は出なくなる)。

**折れたパネルの決まり**:

- 折り目は背の真上の (0, Y)。折る向きは2通りあり、エンジンが自動で決める。
  - 一番奥のパネル(Y が最小): 端へ行くほど手前に出る。とじるときは奥へ倒れ、開くと奥から起き上がる。
  - それより手前のパネル: 逆向きに折れ、端へ行くほど奥へ引く。とじるときは手前へ倒れ、開くと手前から起き上がる。
  - ただし、奥にある「端が手前に出る向き」のパネルに近すぎて、逆向きにすると端で交差するパネル(全幅どうしなら Y の差が約 300 未満。奥の丘と手前の丘の2枚重ね、波の帯の3枚重ねなど)は、そのパネルと同じ向きになる。奥から順に決まるので、近い間隔で並べたパネルはすべて同じ向きにそろう。
- X の位置での根元は `Y ± |X| × tan(12°)`(ページの端 X=±700 で約 150)。一番奥は手前へ、逆向きのパネルは奥へずれる。**折れたパネルの近くに置く物は、この分を見込んで Y を決める。** Y で決めたつもりの前後がその位置では入れ替わるパーツには、エンジンが警告を出す(直す Y の値つき)。
- 起き上がりはページの開き角だけで決まる(エンジンが固定)。開ききると垂直に立ち、めくるとページの間に収まる。左右の板は重ならず、折り目も離れない。このため `delay` `lean` `sway` と開いた直後のぷるぷるは効かない。`dyn` で使えるのは `op` `clip` `sc` `lift` `dy`。`anim` は使える。
- **手前へたたまれるパネル(負の向き)は、高さを「920 − Y」程度までにする。** それより高いと、とじるときにページの手前へはみ出して目立つ(エンジンが警告を出す)。城や塔のような高い物を背の上に置くときは `fold: 12` で奥へたたむ向きにする。
- `fold` を書くと角度と向きを指定できる。正の値は一番奥と同じ向き(端が手前)、負の値は逆向き(端が奥)。大きくすると深く折れ、めくりの早い段階から起き上がる。小さくすると平らに近づくが、開ききる直前に一気に立つ。`fold: 0` は折らずに左右の板を別々に立てる方式で、めくり途中に左右が重なって見える。
- 切り分けたパーツ(折れたパネルを含む)では、**絵が `w0×h0` の箱からはみ出した部分は切れる**。上に突き出る飾りや、`anim` で回す絵は、箱を大きく取って中に収める(片ページに収まるパーツは、はみ出してよい)。
- 切り分けたパーツは `dx` などで動かせないので、**動かす物・`yaw` を付ける物には `nosplit: true`** を付ける。
- **`dx` で背を越えて動くパーツは、根元がいまある側のページに自動で付け替わる。** `side` は出発側のページを書く。めくられるときは、そのとき乗っている側のページと一緒にたたまれる。見開きの終わりに背の真上(幅が左右にまたがる位置)で止めると、はみ出した側はページの上を通るので、止める位置はどちらかのページの中にする。

## 段々の構造物 terrace()

城・塔・神殿・ひな壇・階段状の町のような「奥行きのある建物」は、板1枚で描かずに `terrace()` で組む。壁を手前から奥へ並べ、壁の上に床(屋根・テラス)を渡した形で、本物の飛び出す絵本の箱の仕掛けと同じように、ページの開閉に合わせて壁と床が一緒に起き上がり、たたまれる。開閉の動きはエンジンが決めるので、書くのは段の寸法と絵だけ。

```js
pieces: [
  ...terrace({ X: 0, Y: 520, step: 70, tiers: [       // tiers は手前から順。奥の段ほど高くする
    { w: 880, h: 70,  d: 60, top: '#e6f3f0', art: (w, h) => `...` },                 // 石の台
    { w: 860, h: 300, d: 36, td: 96, top: (w, d) => `...`, art: w => `...軒先...` }, // 軒先だけ描いた壁(下は透明)+屋根の面
    { w: 700, h: 250, d: 60, top: false, art: (w, h) => `...` },                     // 本殿の壁
    { w: 150, h: 600, top: false, art: (w, h) => `...` },                            // 屋根飾り
  ] }),
]
```

| キー | 意味 |
|---|---|
| `X`, `Y` | いちばん手前の壁の根元。**`X: 0`(背の上)に置くのが基本**。壁は背で山折りになり、建物の角がこちらを向いて、左右の面が別の向きに見える(左の面は少し暗くなる)。片ページに収めると(どの段も背を越えない `X`)、壁は正面向きの平らな板が並ぶだけになり、立体感は弱い |
| `step` | 段の奥行きの既定(70)。段ごとに `d` で変えられる |
| `tiers[].w`, `h` | 壁の幅と高さ。**奥の段ほど高く**する(手前の段に隠れない部分だけが見える) |
| `tiers[].art` | 壁の絵。文字列か `(w, h) => 文字列`。上のほうだけ描いて下を透明にすれば、軒先・欄干・アーチになり、後ろの壁が透けて見える |
| `tiers[].top` | 壁の上に渡す床の絵。色の文字列か `(幅, 奥行き) => 文字列`。`false` で床なし。最後の段は既定で床なし |
| `tiers[].d` | 次の壁までの奥行き |
| `tiers[].td` | 床の奥行き(既定 `d`)。屋根を2つ先の壁まで渡すときに書く |
| `tiers[].lip`, `over` | 床を壁より手前へ・左右へ出す量(ひさし) |
| `tiers[].opt` | その壁だけの `pc` オプション(`glow` など) |
| `dyn` | 全部の壁に掛かる動き。使えるのは `op` と `sink` |
| `fold` | 背の上に置いたときの折る角度(既定 -30。負は山折りで、角がこちらを向く。-25〜-40 が目安)。浅い角度や正の値(谷折り)にすると、屏風に描いた1枚絵のように見えて立体に見えない |

- 床はページと平行な板で、壁の上端に手前の辺が付く。奥の辺は次の壁に当たる位置に来るので、**床の奥行き `td` は「その先の壁までの `d` の合計」以下**にする(超えると奥の壁を突き抜ける)。
- **段の数は 3〜6 が目安。** 「台 → 軒先 → 壁 → 軒先 → 壁 → 飾り」のように、軒先や欄干の段をはさむと立体感が出る。壁の絵は正面から見た平らな絵でよい(立体感は段の重なりが作る)。
- 山折りの壁は端へ行くほど奥へ引く(X の位置で `|X| × tan(30°)` ≒ `|X| × 0.58`)。いちばん手前の角 `Y` は 560〜620 に置き、**どの段も `根元の Y + 高さ` が 980 以下**になるようにする(とじるとき手前へ倒れるので、超えるとページからはみ出す。エンジンが警告を出す)。
- 高さの合計が大きいので、カメラを引く(`d: 800〜950, tilt: 60〜64, cz: 280〜320`)。**`yaw` を -9 → 9 のようにゆっくり回す**と、面の向きの違いと段の重なりがよく見える。
- **せり上がる・沈む**: `dyn: tl => ({ sink: (1 - u) * 高さ, op: u > 0 ? 1 : 0 })`。`sink` は根元より下へ沈める量で、沈んだ分はページの下に隠れる。床も一緒に上がってくる。
- 人物を段の上に立たせるなら、その段の壁の少し奥(Y を 4〜10 小さく)に置き、`lift` を壁の高さにする。

## dyn と anim

`dyn(tl)` はパーツ全体の変形を返す。返せるキーは次のとおり。

| キー | 意味 |
|---|---|
| `dx`, `dy` | 根元の移動(見開き座標) |
| `lift` | 浮かせる高さ(オプションの `lift` を上書き)。負にするとページの下に沈み、沈んだ分は根元の線で切られて見えなくなる(めくり途中でも出てこない) |
| `sc` | 拡大率(根元基準)。`pop(tl, t0)` と組むと「ぽん」と現れる |
| `op` | 不透明度。0 で非表示 |
| `rz` | 立った面内の回転(度)。パーツ自身の足元が中心(傾く・倒れる・くるくる回る) |
| `rzBase` | ページ上の根元が中心の回転。`lift` で浮いた物を根元から振り回す(倒れる木につかまった人物など) |
| `lean` | 後ろへ倒す(度) |
| `clip` | 上から隠す割合 0〜1。下から伸びる表現 |
| `sink` | 根元より下へ沈める量(px)。沈んだ分は隠れる。地面からせり上がる・沈む表現(構造物 `terrace` でも使える) |

`anim(tl, el, q)` は絵の中の一部(腕・しっぽ・炎など)を動かす。絵の側で `<g class="aR">` のようにクラスを付けておき、`rot(qs(el, q, '.aR'), 角度, 中心x, 中心y)` で回す。`q` はキャッシュ用の入れ物でそのまま渡す。

```js
pc(70, 720, 120, 226, A.momo({ armR: -150 }), {
  k: .82,
  dyn: tl => ({ lift: 10 * abs(sin(tl * 3.5)) }),                 // ぴょんぴょん
  anim: aArm('.aR', tl => -150 + 20 * sin(tl * 7)),               // 手を振る
})
```

## カメラ

省略すると、ゆっくり寄る穏やかな動きが自動で付く。指定は基本姿勢との差分で書く。

```js
cam: {
  start: { d: 400, cx: 60 },                        // 開いた時
  end:   { d: 200, cx: 20, cz: 165 },               // 次へめくる直前
  keys:  [[2.5, { d: 130, cx: -30 }], [7.3, { d: 1150, tilt: 72, cy: 60, cz: 560 }]],   // 途中 [tl, 姿勢]
}
```

| キー | 基本 | 意味 |
|---|---|---|
| `d` | 330 | 引き。大きいほど遠い。寄り 130〜250、標準 300〜450、高い物を見せる 1100〜1500 |
| `tilt` | 52 | 見下ろし角(度)。0 で真上から、90 で真横から。高い物は 70〜75 |
| `yaw` | 0 | 机の上での回転(度)。±3 程度で十分 |
| `cx`, `cy`, `cz` | 0, -30, 150 | 注視点。`cz` は高さ |

高さ 500 を超える物(塔・巨木など)を見せるときは `tilt: 70〜74`、`d: 1100〜1500`、`cz: 高さの4〜5割` にする。必ず `--spread N` で画面内に収まっているか確かめる。

## 色調とゆれ

- `grade: tl => [色, 濃さ]` … 画面全体に色を乗算する。夜は `['#3d52a8', .56]`、うす暗い室内は `['#b79ac6', .36]`。めくり際の出入りはエンジンが自動でなじませる。`tl` で濃さを変えれば夜明けなどになる。
- `shake: tl => [x, y]` … 衝撃の瞬間だけ使う。`26 * Math.exp(-3.4 * k) * sin(k * 47)` のような減衰振動にする。
